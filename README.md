# 📷 webcam-streamer

Легковесный, безопасный и высокопроизводительный сервис на **Go** для трансляции видеопотока с USB веб-камер в реальном времени.

Проект спроектирован с упором на минималистичность (**ноль внешних тяжелых веб-фреймворков**) и максимальную производительность. Передача видео осуществляется по протоколу **MJPEG (Motion JPEG)**, что обеспечивает минимальную задержку и поддержку всеми современными браузерами «из коробки» (через стандартный тег `<img>`) без использования CGO, FFmpeg или OpenCV.

Приложение полностью адаптировано для работы на серверах за роутерами (например, **Keenetic**) с настроенной маршрутизацией.

## 🔒 Безопасность и защита

Приложение разработано с учетом защиты от распространенных сетевых атак:
*   **Защита от уязвимостей конфигурации:** Сервер принудительно завершает работу, если в системе не заданы секреты или длина `JWT_SECRET` менее 32 символов (защита от перебора подписей).
*   **Безопасное хранение паролей:** Аутентификация администратора завязана на криптографически стойкие хэши **Bcrypt** с адаптивной задержкой времени проверки, что нивелирует тайминг-атаки (Timing Attacks).
*   **Защита от Брутфорса (Rate Limiting):** Встроенный middleware на базе `golang.org/x/time/rate` отслеживает входящие IP-адреса и блокирует запросы (HTTP 429 Too Many Requests) при превышении лимита попыток входа, логируя подозрительную активность.
*   **Умный Rate-Limiting за роутерами/Nginx:** Middleware извлекает IP из заголовка `X-Forwarded-For`, сформированного Nginx. Это гарантирует, что при атаке заблокируется только конкретный злоумышленник, а не все пользователи.
*   **Автономность токенов:** Используется полноценный стандарт **JWT (RFC 7519)** с подписью **HMAC-SHA256**, реализованный силами стандартной библиотеки для исключения уязвимостей в сторонних зависимостях. Сессия не сохраняется в браузере, а горутины и TCP-соединения **мгновенно сбрасываются при закрытии вкладки пользователем**.
*   **Защита диска от переполнения (Авторотация логов):** Все логи пиньгуются в реальном времени параллельно в консоль и в файл `log.txt`. При превышении лимита `MAX_LOG_SIZE_MB`, заданного в `.env`, файл атомарно и автоматически очищается до нуля байт встроенным ротатором на чистом Go.

## 📡 Спецификация API Эндпоинтов

Все эндпоинты в случае ошибок возвращают консистентный JSON-ответ в формате:
```json
{
  "status": 401,
  "error": "Unauthorized"
}
```

### 1. Аутентификация (Публичный с защитой от брутфорса)
*   **URL:** `/api/login`
*   **Метод:** `POST`
*   **Тело запроса (`application/json`):**
    ```json
    {
      "username": "admin",
      "password": "your_secure_password"
    }
    ```
*   **Успешный ответ (HTTP 200 OK):**
    ```json
    {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOi..."
    }
    ```

### 2. Получение списка доступных камер (Требуется JWT)
*   **URL:** `/api/cameras`
*   **Метод:** `GET`
*   **Заголовок авторизации:** `Authorization: Bearer <ваш_jwt_токен>`
*   **Успешный ответ (HTTP 200 OK):**
    ```json
    [
      {
        "id": "/dev/video0",
        "name": "Logitech HD Pro Webcam C920"
      }
    ]
    ```

### 3. Переключение камеры «на лету» (Требуется JWT)
*   **URL:** `/api/cameras/switch`
*   **Метод:** `POST`
*   **Заголовок авторизации:** `Authorization: Bearer <ваш_jwt_токен>`
*   **Тело запроса (`application/json`):**
    ```json
    {
      "camera_id": "/dev/video1"
    }
    ```

### 4. Видеопоток MJPEG (Требуется JWT)
*   **URL:** `/api/stream`
*   **Метод:** `GET`
*   **Авторизация:** Токен принимается как в заголовке `Authorization`, так и в Query-параметре `/api/stream?token=<токен>` (для прямой интеграции в HTML-тег `<img src="...">`).
*   **Ответ:** Бесконечный стрим бинарных JPEG-кадров со специальным типом содержимого: `multipart/x-mixed-replace; boundary=frame`.

## 🧪 Руководство по тестированию

Благодаря инъекции интерфейсов бизнес-логика тестируется в полной изоляции без подключения реального оборудования. Тесты покрывают сценарии успешных авторизаций, работу с токенами, сбои оборудования, ротацию логов на диске и конкурентную обработку видеопотоков.

### Запуск тестов

```bash
go test -cover ./...
```

Для обхода конфликтов кэша локального тулчейна и отключения предварительного статического анализа используйте команду:
```bash
GOTOOLCHAIN=local go test -vet=off -cover ./...
```

### Детальный анализ покрытия
Чтобы посмотреть, какие именно строки кода покрыты тестами, сгенерируйте HTML-отчет:
1. Запустите сбор метрик:
   ```bash
   go test -coverprofile=coverage.out ./...
   ```
2. Откройте интерактивную визуализацию в браузере:
   ```bash
   go tool cover -html=coverage.out
   ```

## 🚀 Безопасный деплой на сервер в одну строку

Развертывание проекта полностью автоматизировано и происходит **напрямую на стороне сервера**. Секреты (включая `JWT_SECRET`) никогда не передаются по сети и не сохраняются в Git-репозитории.

При первом деплое скрипт автоматически определит внешний IP-адрес роутера, сгенерирует криптостойкий JWT-ключ и откроет интерактивный редактор `nano` прямо в окне вашего терминала. В `nano` вы вводите **пароль обычным текстом** (в поле `ADMIN_PASSWORD`), а скрипт автоматически перехватит его, преобразует в безопасный **Bcrypt-хэш** с помощью Docker и запишет в закрытый файл `.env`.

### Команда для запуска на удаленном сервере:
Подключитесь к вашему серверу по SSH и выполните следующую связку команд (замените URL на ваш актуальный репозиторий):

```bash
curl -sSLO https://raw.githubusercontent.com/AlexanderV823/webcam-streamer && chmod +x deploy.sh && ./deploy.sh
```

### 📊 Управление и мониторинг
*   Благодаря правилу `restart: always` в Docker Compose, контейнеры **автоматически запускаются при старте операционной системы** сервера.
*   При каждом новом деплое скрипт автоматически производит очистку системы (`docker image prune -f`), удаляя старые образы-сироты (`<none>`) и освобождая дисковое пространство.
*   Посмотреть статус работы контейнеров: `sudo docker compose ps`
*   Посмотреть логи запросов в реальном времени: `sudo docker compose logs -f`
*   Лог-файл приложения проброшен на хост-машину и доступен по адресу: `/opt/webcam-streamer/log.txt`
